# ReportAutomation

보고서 자동화 런처, Python 보조 엔진, Excel 산출 add-in을 관리하는 별도 저장소입니다.

Current version: `0.0.1`

## Structure

- report_automation_launcher: Windows WinForms launcher
- report_automation_engine: Python report draft/table analysis engine
- report_automation_addin: Excel VBA output engine called by the launcher

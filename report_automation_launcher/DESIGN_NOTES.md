# Launcher UX Notes

- Keep the launcher as a work-focused desktop tool, not a marketing-style app.
- Preserve the four-step workflow: file registration, data review, writing rules, run/results.
- Show state before asking the user to act: file readiness, detected table count, selected banner count, and output readiness should be visible before execution.
- Prefer compact WinForms controls and clear status text over decorative panels.
- Banner controls should reflect detected Excel structure; do not ship project-specific default banners.

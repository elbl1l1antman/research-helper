# Launcher-Based Alpha Direction

보고서 자동화 프로젝트는 이 단계부터 런처 기반 프로그램으로 재개발합니다.

## 제품 구조

- `report_automation_launcher`
  - 사용자가 직접 실행하는 주 프로그램입니다.
  - 파일 선택, 데이터 확인, 작성 규칙 선택, 실행/결과 확인 UX를 담당합니다.

- `report_automation_addin`
  - 런처가 호출하는 Excel 내부 산출 엔진입니다.
  - 사용자가 직접 만지는 UI가 아니라, Excel 산출 시트를 안정적으로 만드는 역할입니다.

- `report_automation_engine`
  - Python 기반 문장 생성/표 구조 분석 보조 엔진입니다.
  - 런처가 별도 프로세스로 호출해 문장 초안 TXT를 생성합니다.

## Alpha 1 범위

- Excel 집계표 선택
- 표 목록과 실제 탐지된 가로배너 목록 미리보기
- 분석에 사용할 배너 추천 선택, 수동 체크, 순서 이동, 목록 제외
- 보고서 유형/문체/배너/제목 접두어 설정
- 출력 형식, HWPX/PPTX 템플릿, 구성요소, 소수점 자리, 차트/삽입표 방식 선택
- LLM 제공자, 모델, API 키 입력 여부 선택
- Excel 산출 시트 생성
- Python 문장 초안 TXT 생성
- 결과 탭에서 산출 엑셀/초안 TXT 열기
- 문장 초안 미리보기와 클립보드 복사
- 문장별 수정/복사/검토본 저장
- QA 경고 필터 기본 제공
- 실행 로그와 완료 요약 표시

## 아직 비활성화된 범위

- HWP/HWPX 문서 직접 생성(옵션 선택과 템플릿 경로 저장은 가능)
- PowerPoint 문서 직접 생성(옵션 선택과 템플릿 경로 저장은 가능)
- 문장별 리뷰/수동 편집 UI
- Python 엔진과의 실시간 문장 미리보기 연결

## 다음 알파 후보

1. 검토본을 Excel 산출 시트 또는 별도 검토 시트로 되돌려 쓰기
2. QA 경고 규칙을 프로젝트별 설정 JSON으로 분리
3. HWPX 템플릿 생성/삽입 단계 구현
4. PPTX 요약 슬라이드 생성 단계 구현
5. Python 런타임/엔진 파일 패키징 방식 정리

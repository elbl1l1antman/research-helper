# 조사 보고서 차트 작업 합의

이 문서는 질문·답변으로 합의한 사항을 기록한다. 이전 [명세](2026-11-13-survey-chart-output.md)와 [차트 검토](../plans/2026-11-13-survey-chart-review.md)·[HWPX 삽입](../plans/2026-11-13-hwpx-chart-emf.md) 초안에서 충돌하는 내용은 이 문서가 우선한다.

## 생성 대상

- 응답자 특성표를 제외하고 집계표당 대표 차트 하나를 만든다. `전체` 값만 사용하며, 확인된 `합계`/`계`도 허용한다. 하위 배너를 합산해 전체를 만들지 않는다. 전체가 없으면 차트만 보류한다.
- 대표 지표는 응답 비율 우선, 비율이 없으면 매출·종사자 수 등 실제 지표를 사용한다. 사례수는 보기나 지표로 쓰지 않는다. 비교할 값이 하나뿐이면 차트를 만들지 않는다. `0`은 유효한 값이고, 비교 대상 보기 중 `-`나 빈 값이 있으면 그 차트만 보류한다.
- 집계표의 보기 순서를 보존한다. 최대값 강조와 표시값 우선 원칙을 유지한다. 긴 보기는 자르지 않고 줄바꿈하고, 겹침이 남아 있으면 수정 필요로 표시한다. 가로 막대로 자동 전환하지 않는다.
- 같은 BASE에서 상호 배타적인 두 보기가 전체를 구성한다고 확인한 경우 도넛형, 나머지는 세로 막대. 두 비율의 합만 100인 경우에는 세로 막대로 진행하고, 사용자가 실제 이분형임을 확인하면 도넛으로 변경할 수 있다.

## 공통 PPTX 서식과 검토

- 샘플 데이터만 담은 편집 가능한 세로 막대·도넛 PPTX를 제공한다. 사용자 편집본은 모든 프로젝트의 공통 기본 서식으로 등록한다. 기존 업무용 PPTX에서 임의 차트를 등록하는 기능은 제외한다.
- 템플릿 차트의 디자인을 살리고 실제 집계값을 교체한다. 서식 등록 시 예제 값과 문항별 줄바꿈은 공통 설정으로 저장하지 않는다. 슬라이드당 차트 한 개, 슬라이드 바깥 제목은 별도로 표시하고 차트 자체에는 제목을 넣지 않는다.
- 차트 대상은 기본 선택. 검토 화면은 문제가 있을 때 자동으로 열며, 사용자가 필요할 때 직접 열 수도 있다. 수정 필요 차트는 검토용 PPTX로 손볼 수 있게 하고, 검증된 값이 없는 항목을 0으로 채우지 않는다.
- 최초 한글 생성은 PowerPoint에서 차트 객체만 복사한다. 별도 텍스트·도형은 포함하지 않는다. PowerPoint가 없으면 본문과 표를 생성하고 차트는 보류한다. 이후 PowerPoint 편집은 항목 줄바꿈과 막대 간격 등 모양을 바꿀 수 있지만 수치는 집계표와 일치해야 한다. 기존 HWPX를 자동 교체하지 않으며 사용자가 직접 붙여넣는 방법만 안내한다.

## 한글 배치와 실증 순서

1. `분석문 → 위쪽 그림 캡션이 달린 1×1 표 → 집계표` 순서. 공간이 되면 같은 쪽에 두고, 맞추려고 글씨를 억지로 줄이지 않는다.
2. 바깥 표는 테두리 없는 1×1 표이며 `글자처럼 취급`, 번호 종류 `그림`. 위에 `<그림 3-1> 문항명`처럼 캡션을 붙인다. 앞자리는 사용자가 지정하고 뒷자리만 한글 그림 자동 번호를 사용한다. 기존 표 번호와 독립이다.
3. 셀 안에는 차트 객체만 **확장 메타파일(EMF)**로 붙여넣어 셀 안쪽 폭에 맞춘다. 안쪽 개체 번호 종류는 **없음**. 저장 후 그림 번호 중복과 래스터·OLE 대체를 검사한다.
4. 선택된 차트가 보류되면 그림 캡션과 **텍스트 없는 빈 셀**을 남긴다. 제외·해제된 차트의 자리는 만들지 않는다. 런처에 문항, 그림 번호, 이유와 수동 붙여넣기 방법을 표시한다.
5. 첫 단계는 가짜 세로 막대·도넛 및 빈 자리 하나로 실제 한글 저장·재열기 실증이다. 성공하기 전에는 자동 삽입을 런처에 노출하지 않는다. 다음으로 공통 PPTX, 집계표 대표 차트 선택, 검토 UX를 연결한다.

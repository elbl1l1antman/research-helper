# 조사 보고서 차트 출력 명세

## 이전 요청과 적용 범위

| 이전 요청 | 이번 적용 |
| --- | --- |
| Excel 집계표를 읽고 분석문·차트·삽입표 산출. VBA 단계에서는 Excel이 최종이며 문서 작업은 사용자가 선택 | 기존 Excel 산출과 표·본문 실행은 그대로 두고 차트 검토 및 삽입은 명시적으로 선택 |
| 차트 생성 전 사용자 개입. 가능한 세로 막대, 이분화된 선택지는 원형, 가장 높은 값 강조 | 문항·배너·지표별 채택과 유형 확인. 구성비가 아닌 두 값은 막대 |
| 보고서 작성 전에 차트·그래프만 담은 PPT 출력 | 별도 `차트 검토 PPT 만들기`. PowerPoint에서 데이터와 색을 편집할 수 있는 차트 객체 |
| 차트 이미지는 허용하되 HWP/HWPX는 선택 붙여넣기로 메타파일 사용. 표는 이미지 금지 | 한글에는 확인된 EMF만 붙여넣기. PNG/JPEG, OLE 및 형식 미확인 붙여넣기로 대체 금지. 표 경로는 그대로 유지 |
| 표기 기본 소수점 한 자리. 사용 글꼴 지정. 차트 상단에 항목명이 있으므로 내부 제목 삭제 | 원본 표시값을 우선하고 명·원·점·%를 섞지 않음. 상단 제목 한 번, 축·범례·값 레이블 글꼴 지정 |
| 대시보드용 시계열 선그래프, KPI·진행 막대와 인포그래픽, A4/B5, 사용자 슬롯 | 기관 대시보드는 별도 산출물. 이번에는 변경하지 않음. 조사 보고서 시계열과 다중 시리즈도 다음 범위 |
| HWPX가 주 업무, PPT는 우선도가 낮음 | PPT는 최종 보고서 재개발이 아니라 차트 확인·편집용 도구. HWPX 삽입 검증이 최종 승인 기준 |

근거는 이 대화의 이전 요청과 `origin/main` `04468b2` (`0.0.42`) 소스다. 현재 VBA는 `보고서_차트데이터`를 만들며, `report_package.py`가 `table_key`, `series_group`, `category`, `measure`, `value`, `display_value`, `sort_order`, `include_chart`, `source_cell`을 읽는다. `document_writer.py`의 CLI는 편집 가능한 차트를 만들지만 `table_key` 단위로 합쳐 두 항목을 무조건 원형으로 판단하고 최대 10개를 자른다. 이 writer는 템플릿 테마를 쓰되 슬라이드 배치를 복제하지 않는다. 런처의 기존 차트 출력 콤보는 차트 산출을 실행하지 않으며, 한글 COM은 `charts_deferred`만 기록한다.

## 차트 공통 규칙

- 새 경로는 Excel을 다시 읽지 않고 `report_package.json`의 차트 후보를 소비한다. 구분 키는 `[table_key, series_group, measure]`; 같은 조합에 여러 그룹이 섞인 것으로 의심되거나 보기명이 중복되면 임의 합산하지 않고 출처를 표시한다. `include_chart`는 초기 추천, `sort_order`는 초기 보기 순서다. 초기 추천은 최대 10개지만 실제 내보내기는 사용자의 선택을 조용히 자르지 않는다.
- 자동 원형은 **같은 BASE에서 상호 배타적인 보기 두 개가 전체를 구성한다고 확인**했고, 그 두 보기가 모두 선택되었으며 단위가 `%`, 값이 각각 `0..100`, 합계가 `100 ± 0.2` %p일 때만 사용한다. 패키지에 의미 정보가 없으면 기본 막대다. 사용자가 원형으로 지정해도 이 조건을 생략할 수 없다. 복수응답, 상위 두 항목만 선택, 매출과 예상 매출은 원형 대상이 아니다.
- % 축용 값의 계약은 `0..100`의 퍼센트 포인트다. 임의로 100을 곱하지 않는다. `display_value`가 있으면 그대로 표시하고, 없을 때만 기본 1자리와 단위를 붙인다. 값 `0`과 누락/`-`는 구별한다. `NaN`, 무한대, 불일치하는 단위는 차트 검토에서 오류로 표시한다. 최대값은 동률을 모두 강조하고, 원형의 나머지 조각은 구분 가능해야 한다. 음수 막대는 0 기준선을 유지한다.
- 차트별 표시 설정: 채택 여부, 보기 체크, 유형(`auto`, `column`, `pie`), 제목, 기본색과 강조색, 글꼴. 초기 기본값은 맑은 고딕, `357B99`/`C65B39`. 제목은 차트 밖에만 표시. 출처 셀과 BASE는 확인되는 경우에만 표시한다. QA는 단위, 보기, 범위와 실패 이유를 보여준다.
- 차트 선택과 설정은 실행 결과 폴더에 저장한다. 다른 패키지나 바뀐 후보의 설정을 조용히 재적용하지 않는다. 원본 Excel·HWPX·PPTX 및 기존 로컬 진단 로그는 수정하거나 커밋하지 않는다.

## 납품과 승인 기준

1. **차트 검토:** 런처에서 기존 package를 열고 차트별 선택·미리보기 후 편집 가능한 차트 전용 PPTX를 생성한다. 내보내기 전 잘못된 선택을 차트별로 안내한다. 차트 없는 문서 경로는 회귀하지 않는다.
2. **한글:** 선택된 차트만 `표 → 차트 → 출처` 순으로, 한글 본문 폭 이내의 독립 문단에 삽입한다. Excel/아래한글 COM을 사용하고, PowerPoint 설치는 한글 경로의 필수 조건으로 만들지 않는다. 실제 한글에서 EMF 유지가 입증되지 않으면 기능을 기본 노출하지 않는다. 차트 삽입 실패 시 삽입을 하지 않았음이 확인될 때만 나머지 보고서를 저장하고 오류를 남긴다. 확인할 수 없으면 현재 구간을 중단하고 마지막 안전한 체크포인트를 유지한다.

환경은 Windows, 기존 Python 3.12·WinForms·`python-pptx`·`pywin32`, 신규 외부 의존성 없음. 시험용 산출물은 `outputs/`에 둔다. 사용자 PPTX 레이아웃 복제, HWP 네이티브 차트, 시계열/다중 시리즈, 기관 대시보드 재설계는 이번 승인 대상이 아니다.

# HWPX 수치 인식과 자동 재개

- [x] 셀 계약에서 명시적 BASE, `전 체`/`■전체■`와 사례수 헤더를 읽는다. 실제 조사 대상 조건이 확인되지 않으면 전체 행만 보고 BASE를 추정하지 않는다. 평균·합계 단위는 헤더에서 확인한다.
- [x] VBA가 수치 미탐지로 표시한 문항에만 계약 기반 복구를 적용한다. 동일한 측정 단위와 명시적 전체 행에서 찾은 표시값만 사용하고, 사용자 수정문·기존 정상 문장은 보존한다. 복구 경로와 근거 셀을 기록하고 모호한 항목의 경고는 유지한다.
- [x] 한글 writer는 완료 문항 경계의 문서와 위치 마커를 보관한다. 두 저장 위치를 번갈아 사용해 문서 저장과 재개 기록 사이의 중단에도 직전 정상본을 보존한다. 입력/설정/문서 해시가 맞을 때만 이어 쓰고 최종본에서 마커를 제거한다.
- [x] 런처에서 같은 입력·양식·서식·출력 범위를 다시 실행하면 작업 Excel과 QA 산출물을 재사용한다. 새 입력은 별도 작업으로 시작하며 여러 런처의 동시 한글 쓰기를 차단한다.

## 검증

- Python 228개 통과(1개 건너뜀), 독립 실행과 한글 진행 감시 검사 통과.
- 전체 데이터 QA: KISDI 132문항, 지역서점 31문항, 차단 오류 0건. 수치 미탐지는 각각 21건, 1건 복구. KISDI에서 제목과 열 헤더의 평균/합계 표기 충돌 2건은 검토 경고 유지.
- 지역서점 2문항 HWPX: 1문항 저장 후 작성기 종료, 재개 후 2문항/3표와 재개 마커 제거 확인. 독립 런처의 31문항 실행에서도 9문항 저장 후 같은 옵션으로 다시 실행해 10번째부터 시작하는 것을 확인.

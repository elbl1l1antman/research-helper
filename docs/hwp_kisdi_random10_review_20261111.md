## 통과한 검사

- Excel 원본과 해시가 같은 사본을 읽기 전용으로 다시 열어 `Range.Text`를 추출 결과와
  대조했다. 합의된 공백·장식기호 정리 규칙을 적용한 기준 셀 1,910개에서 불일치 0건이다.
- HWPX 10개 본문 구간과 18개 독립 표 객체를 확인했다. 가로 분할 4개 표를 포함하며,
  18개 모두 실제 Excel 붙여넣기 경로를 사용했다. 그림이나 계약 기반 대체가 아니다.
- 저장 XML의 기준 셀 2,112개(메타 행 및 반복 열 포함)의 좌표·병합·표시값·머리행 플래그가
  계획값과 일치했다. 최대 표 폭은 42,100 HWPUNIT, 본문 폭은 42,520 HWPUNIT였다.
- 아래한글에서 다시 열었고, 같은 한글에서 내보낸 PDF의 페이지 수는 모두 46쪽이었다.
  PDF 전체를 렌더링해 페이지 흐름을 확인했다. 2~3쪽 등 이어지는 표에서 머리행 반복을 확인했다.
- 원본 Excel, 작업용 입력, 산출 Excel, 템플릿, 프리셋의 해시가 검증 전후 일치했다.

## 편집·인쇄에서 발견한 문제

1. **표 하단 잘림.** 6쪽의 `T0021` 두 번째 분할표가 PDF 페이지 하단에서 끊긴다. 7쪽은
   그 표의 다음 행이 아니라 세 번째 가로 분할표부터 시작한다. 값은 HWPX XML에 남아
   있으므로 파일의 데이터 유실과는 구분한다. 3·11쪽도 페이지 끝에 붙어 있다. 다음에는
   세로 병합 그룹의 행 높이와 한글의 페이지 분할 설정을 함께 검증해야 한다.
2. **출처/안내만 남은 페이지 4쪽.** 12·16·36쪽은 출처만, 42쪽은 차트 안내와 출처만
   있다. 표의 마지막 행과 출처를 함께 배치하거나 출처를 각 표에 연결한 뒤 문항 사이 강제
   페이지 나눔을 적용할 필요가 있다.
3. **BASE 안내 과다.** 17쪽 `T0045` 등에서 BASE 조건에 응답 보기까지 포함돼 여러 줄을
   차지하고 페이지마다 반복된다. 명시된 BASE 셀의 조건과 보기 헤더를 분리해야 한다.
4. **본문 검토 필요.** 사전검증은 오류 0건, 경고 77건이다. `T0035`·`T0041`·`T0084`는
   분석용 전체 기준 비율을 찾지 못했다. 표 수치가 없는 것이 아니라 분석문 생성 규칙이
   해당 집계 유형을 처리하지 못한 것이다. 마지막 46쪽의 QA도 한 문단에 이어져 있다.

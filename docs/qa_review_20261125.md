## 확인했지만 문제없던 항목

- 천 단위 쉼표: 사례수 `(#,###)`, 금액 `#,###,###`, 평균 `##,###.##` 형식 모두 정상
- 사례수 열: 텍스트 폭에 맞춘 좁은 열, 줄바꿈 없음
- 표 번호: 분할 표도 같은 번호 유지(`〈표 8〉 … [1/2]`, `[2/2]`), 재번호 없음 — 67개 원표 = 표 번호 67개
- 신문산업 서식 프리셋·KoPubWorld 바탕체 적용, 여백(위 10 · 좌우 20 · 아래 15mm) 적용

## 이어서 검증하는 방법

검수 도구는 `tools/qa/`에 있다(로컬 Windows 전용, 한글/Office COM 사용). 산출물은 `outputs/qa_20261125/`(gitignore).
한글 팝업은 클릭하지 않는다. 검수가 띄운 한글 프로세스만 종료한다(시작 전부터 있던 프로세스는 건드리지 않음).

1. **자동 재개 마무리** (남은 4문항, 약 2분):
   ```powershell
   .venv\Scripts\python.exe tools\qa\resume_test.py outputs\qa_20261125\news\news_table_report_alpha_20261125_154626 outputs\qa_20261125\resume --continue
   ```
   기대: `status=ready`, `resumed_sections=8`, `sections_written=12`, `errors=[]`, `recovery_left=false`.
   처음부터 다시 하려면 `outputs\qa_20261125\resume` 폴더를 비우고 `--continue` 없이 실행(5문항에서 강제 종료 → 재실행).
2. **숫자 대조** (새 산출물마다):
   ```powershell
   .venv\Scripts\python.exe tools\qa\numcheck.py test-data\news_table.xlsx <prefix>_report_package.json <prefix>_hwp_writer_report.json <output.hwpx> <prefix>_hwp_style_config.json
   ```
   기대: `excel_vs_package_issue_count=0`, `hwpx_tables=tables_expected`, `hwpx_missing_count=0`.
3. **쪽 렌더링** (사본을 열어 PNG로):
   ```powershell
   .venv\Scripts\python.exe tools\qa\render_pages.py <output.hwpx> <out_dir> --pages 3,14,24 --dpi 150
   .venv\Scripts\python.exe tools\qa\contact_sheet.py <out_dir> <out_dir>\sheet 20 5
   ```
4. **시간 줄이기**: 수정 확인은 `--hwp-max-sections 3~5`로 먼저 돌리고, 전체 67문항(15~17분)은 마지막에 한 번만 실행.
   양식 샘플은 런처 CLI로 실행:
   ```powershell
   report_automation_launcher\bin\ReportAutomationLauncher.exe --workbook test-data\news_table.xlsx --output-dir outputs\qa_20261125\<name> --output "HWPX 보고서" --hwp-template templates\report_template_<variant>.hwpx --hwp-style-preset "<프리셋 이름>" --hwp-max-sections 1
   ```
   차트까지 확인하려면 `--hwp-figure-prefix 1 --hwp-chart-style <서식.pptx>`를 추가.

결함을 고친 뒤에는 위 1~3을 해당 결함의 쪽/문항에 한정해 다시 돌리고, 이 문서의 해당 항목에 결과를 적는다.

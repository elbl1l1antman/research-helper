# PPTX 조사 보고서 구성요소 평가

고객만족도(PSI) 조사 보고서 2종을 참고해, PPT 보고서 초안 기능(`document_writer.py`, `templates/report_template_basic.pptx`)을 어떻게 구성할지 정리했다.
참고 자료는 사용자 PC에만 있으며 저장소에 넣지 않는다. 기관명과 수치는 적지 않고 구조만 기록한다.

## 1. 참고 자료 요약

| 구분 | 참고 A | 참고 B |
| --- | --- | --- |
| 형식 | 한 기관 단독 보고서(95쪽). 기관 안의 사업 6개가 장으로 반복됨 | 통합 보고서에 붙는 기관별 장(8쪽, `2. 기관명`) |
| 용지 | 780×540pt(가로형, 약 1.44:1) | A4 가로(841×595pt) |
| 흐름 | 표지 → 제출문 → 목차 → PART 01 조사 개요 → 02 결과 종합 → 03 기관 결과 → 04 사업별 결과(반복) → 05 요약 → 맺음 | 기관 간지 → 응답자 특성 → PSI 종합 → 고객만족도(1/4~4/4) → 종합 제언 |
| 반복 단위 | 사업(장 1개 = 간지 + 8~9쪽) | 기관(장 1개 = 간지 + 7쪽) |

두 자료 모두 **"대상(기관·사업) 하나 = 같은 쪽 묶음 한 벌"** 구조다.
사용자가 말한 두 납품 형태(기관별 단독 보고서 / 전체 현황 + 기관별 장)는 이 묶음을 어디에 붙이느냐의 차이일 뿐이다.

## 2. 공통 쪽 틀(프레임)

모든 본문 쪽이 같은 틀을 쓴다. 이 틀은 슬라이드마다 그리지 말고 **템플릿의 레이아웃(slide layout)** 에 둔다.

| 요소 | 참고 A | 참고 B | 채우는 값 |
| --- | --- | --- | --- |
| 머리 띠 | 번호 배지 `01` + 제목 | `2-1.` + 제목 | 절 번호, 제목, `(계속)`·`(1/4)` |
| 오른쪽 위 | PART 이름 + 진행 점(○○●○○) | 기관명 | 장/PART 이름, 진행 위치 |
| 핵심 문장 | 제목 아래 ■ 요약 1~2줄 | 제목 아래 굵은 2줄 | 분석문 첫 문장 |
| 단위 | `[단위: 100점 만점]` 오른쪽 위 | `(단위: 명, %)` | 표 단위 |
| 바닥글 | 좌우 로고 + 쪽 번호 | 보고서명 + 쪽 번호 | 템플릿 고정 + 자동 번호 |

## 3. 쪽 유형 목록과 현재 데이터로 가능한지

우선순위: **P1** 현재 package 데이터로 바로 가능하고 효과 큼 · **P2** 약간의 데이터 추가 필요 · **P3** PSI 점수 모형 데이터 필요 또는 템플릿 고정 쪽.

| # | 쪽 유형 | 참고 | 구성 | 데이터 | 우선 |
| --- | --- | --- | --- | --- | --- |
| 1 | 표지 | A1, B(통합본 표지) | 연도, 보고서명, 기관명 배지 | 기존 토큰 | P1 |
| 2 | PART·기관 간지 | A4·14·29·30, B1 | 큰 번호 + 이름 + 하위 목차 | 장 구조에서 자동 | P1 |
| 3 | 표 + 차트 (현재 반복 쪽) | A24·34, B4 | 핵심 문장 + 차트 + 표 + 출처 | 기존 | P1 개선 |
| 4 | 막대 내장 표 | B4·B5, A24 | 행 = 응답자 특성/요소, 오른쪽에 점수 막대 | 교차표 전체 열·배너 행 | P1 |
| 5 | 응답자 특성 | B2 | 위 막대(구분별 색) + 아래 사례수·비율 표 | 배너 사례수 | P1 |
| 6 | 개선 요구(복수 응답) | B7 | 도넛 + 순위 표 | 단일 문항 분포 | P1 |
| 7 | 목차 | A3 | PART 목록 | 장 구조 | P2 |
| 8 | 결과 요약 카드 2×2 | A20·31·81 | 카드마다 제목 문장 + 작은 차트, 최고/최저 표시 | 대상 점수 + 하위 점수 | P2 |
| 9 | 비교표(GAP ▲▼) + 묶은 막대 | A34·74 | 대상 vs 비교 집단 점수, 차이 색 표시 | 비교 집단 점수 | P2 |
| 10 | 연도 추이 | A16·23 | 막대 + 선, 차원별 증감 표 | 전년도 점수 | P2 |
| 11 | 종합 제언 | B8 | 핵심 과제 상자 + 개선 방향 글 | 분석문/LLM 문장(편집 전제) | P2 |
| 12 | PSI 종합 도식 | B3 | 가운데 원(종합 점수) + 차원 상자·가중치 + 요소 점수 | 차원·요소 점수, 가중치 | P3 |
| 13 | IPA 산점도 + 결과표 | A36·77, B6 | 사분면 배경 + 점 + 항목 표 | 중요도(도출) + 만족도 | P3 |
| 14 | 강약점 레이더 + 표 | A27·28·78·79 | 레이더(대상 vs 비교) + 색 칠한 표 | 요소 점수 + 비교 | P3 |
| 15 | 차원별 작은 차트 6개 | A18 | 같은 축의 작은 막대/선 6개 | 차원 점수 × 대상 | P3 |
| 16 | Box-plot 표 | A26 | 요소별 평균·표준편차·IQR 표 + 범위 막대 | 분포 통계 | P3 |
| 17 | 측정 문항 표 | A32·33 | 차원-요소-문항 | 설문지(고정) | P3 템플릿 |
| 18 | 조사 개요 쪽들(배경·절차·모형·척도) | A5~13 | 도식 위주 고정 쪽 | 연도·기관명 토큰만 | P3 템플릿 |
| 19 | 사업별 요약 카드 격자 | A92~94 | 대상마다 카드 3개 | 8번 재사용 | P3 |
| 20 | 맺음 | A95 | 고정 | — | P3 템플릿 |

판단: 참고 자료의 쪽 절반 이상(12~18)은 **PSI 점수 모형 데이터**(차원·요소 점수, 가중치, 도출 중요도, 비교 집단, 전년도)가 있어야 한다.
지금 package는 "교차표 → 표·차트 1쌍"만 담는다. 그래서 1단계는 **쪽 틀·장 반복 구조와 P1 쪽 유형**을 만들고, PSI 쪽은 데이터 형식을 먼저 정한 뒤 붙이는 것이 맞다.

## 4. 지금 PPTX 초안 기능과의 차이

| 항목 | 현재 | 문제 | 제안 |
| --- | --- | --- | --- |
| 템플릿 구조 | 예시 슬라이드 3장(표지/반복/QA)을 복제 | 레이아웃이 1종이라 쪽 유형을 늘릴 수 없음. 복제 슬라이드가 차트 파트를 공유할 위험 | **레이아웃 기반**: 템플릿 레이아웃 이름(`RA_DIVIDER`, `RA_TABLE_CHART`, `RA_SUMMARY_4` …)으로 `add_slide(layout)` 후 이름 붙은 자리 표시자(`RA_TITLE`, `RA_KEY_MESSAGE`, `RA_UNIT`, `RA_CHART`, `RA_TABLE`, `RA_SOURCE`) 채우기 |
| 문서 구조 | 문항 순서대로 1장씩 | PART·장·간지·목차 없음 | 보고서 → PART → 대상(기관/사업) → 쪽 유형의 **구성 계획(JSON)**을 먼저 만들고 그대로 그림. PowerPoint 구역(section)도 PART별로 넣음 |
| 반복 단위 | 문항 | 기관/사업별 반복 불가 | 대상 목록 × 쪽 묶음 반복. 단독본(A형)과 통합본 장(B형)은 번호 방식(`01` / `2-1`)과 오른쪽 위 표시만 다름 |
| 큰 표 | 경고만 남김(41행 표가 슬라이드 밖으로 넘침) | 납품 불가 | 행 기준 자동 분할 + 머리글 반복 + 제목 `(계속)`/`(n/m)`. 열이 넓으면 한글 writer의 분할 계획(`plan_hwp_table`)처럼 보기 열 반복 분할 |
| 차트 | 묶은 세로 막대/원, 최대값 강조 | 비교 대상 구분 없음 | 대상 = 테마 강조색, 비교 집단 = 회색/연한 색, 최고·최저 = 파랑/빨강 원 표시, 데이터 레이블 위, 눈금선 없음. 모든 차트 같은 글꼴·크기 |
| 색·글꼴 | 코드에 일부 고정 | 기관 색으로 못 바꿈 | 템플릿 **테마 색**(accent1 대상, accent2 비교, accent6 부정)만 참조 |
| QA 쪽 | 마지막 슬라이드로 넣음 | 납품본에 내부 QA가 섞임. 글이 슬라이드 밖으로 넘침 | 납품본에서는 빼거나 숨김 슬라이드 + 별도 QA 파일. 넘치면 여러 장으로 |
| 핵심 문장 | 분석문 전체를 본문 상자에 | 쪽 위쪽 1~2줄 요약 자리가 없음 | 분석문 첫 문장 → `RA_KEY_MESSAGE`, 나머지는 노트나 본문 |

## 5. 차트·도형 구현 가능 범위 (python-pptx, PowerPoint 원본 차트)

| 표현 | 방법 | 편집 가능 |
| --- | --- | --- |
| 묶은 막대, 막대+선 | 기본 차트, 선은 콤보(XML 보정) | 예 |
| 도넛 | `DOUGHNUT` | 예 |
| 레이더 | `RADAR_MARKERS` | 예 |
| IPA 산점도 | `XY_SCATTER` + 평균선 위치에 사분면 배경 도형 | 예(배경은 도형) |
| 막대 내장 표 | 표 + 행 높이에 맞춘 가로 막대 차트(축 숨김)를 옆에 정렬 | 예 |
| Box-plot | PowerPoint 상자수염 차트는 python-pptx 미지원 → 누적 막대 트릭 또는 표 | 부분 |
| 최고/최저 원 표시 | 데이터 레이블 위에 타원 도형 | 도형 |

그림(이미지)으로 넣는 차트는 쓰지 않는다. 사용자가 PowerPoint에서 '데이터 편집'으로 고칠 수 있어야 한다.

## 6. 단계 제안

1. **틀**: 레이아웃 기반 템플릿 형식 정의, 구성 계획(JSON) 생성기, 간지·표지·목차·쪽 번호·PART 표시, 큰 표 자동 분할, QA 분리.
2. **P1 쪽**: 표+차트 개선, 막대 내장 표, 응답자 특성, 개선 요구 도넛.
3. **비교 데이터**: package에 대상/비교 집단/전년도 점수 형식 추가 → 요약 카드, GAP 비교표, 추이.
4. **PSI 모형**: 차원·요소·가중치·도출 중요도 형식 추가 → PSI 도식, IPA, 레이더, 작은 다중 차트, Box-plot.
5. **템플릿 고정 쪽**: 조사 개요·측정 문항·맺음은 사용자 템플릿에 그대로 두고 토큰(`{{ORG_NAME}}`, `{{YEAR}}`)만 바꿈.

## 6-1. 1단계 반영 상태

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 구성 계획 | 완료 | `--plan plan.json` (`{"parts":[{"title","table_keys"}]}`). 없으면 PART 1개 `조사 결과`. 빠진 문항은 마지막 PART에 넣고 경고 |
| 목차·간지 | 완료 | 템플릿에 `{{TOC}}` 쪽, `{{PART_NUMBER}}`/`{{PART_ITEMS}}` 쪽이 있으면 자동 생성. 없으면 예전처럼 문항 쪽만 |
| 쪽 틀 토큰 | 완료 | `{{SECTION_NUMBER}}`(PART마다 01부터), `{{PART_TITLE}}`, `{{KEY_MESSAGE}}`(분석문 첫 줄), `{{UNIT}}` |
| 큰 표 행 분할 | 완료 | `(계속)` 쪽, 머리글 반복, 배너 그룹 경계 우선, 잘린 배너 이름 반복 |
| QA 쪽 | 완료 | 숨김 슬라이드 + 12줄씩 여러 장 |
| 기본 템플릿 | 완료 | `python -m report_automation_engine.pptx_report_template`로 다시 만듦 |
| 레이아웃 기반 채우기 | 보류 | 기존 사용자 템플릿 호환을 위해 이번에는 "예시 슬라이드 복제 + 토큰" 방식을 유지 |
| 넓은 표 열 분할 | 남음 | 17열 표는 7pt로 작아짐. 한글 분할 계획을 재사용할 예정 |
| 계속 쪽 표 위치 | 남음 | 핵심 문장 자리가 비어도 표가 위로 올라가지 않음 |

## 7. 검증 방법

- 구조: pptx 스킬 `validate.py`로 스키마·관계·차트 XML 검사(클라우드에서도 가능).
- 내용: `slide_text.py`로 남은 `{{...}}` 토큰, 빈 자리 확인.
- 화면: 로컬 PowerPoint COM으로 슬라이드 PNG를 뽑아 넘침·겹침 확인(로컬 전용).

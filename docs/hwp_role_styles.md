# 한글 보고서의 역할별 표 서식

런처의 **HWP 보고서 서식 설정**에서 기존 `표보기`, `표배너`, `표숫자`를 계속 사용할 수
있다. 머리행·가로배너·세로배너·BASE 데이터 행을 따로 설정할 때는 해당 스타일의 **개별**을
켠다. 값 셀은 기존 `표숫자`를 사용한다. 다른 역할의 설정은 함께 바뀌지 않는다.

| 역할 | 개별 스타일 | 개별 사용 안 함 |
| --- | --- | --- |
| 머리행 | `표머리행` | `표배너` |
| 가로배너 | `표가로배너` | `표배너` |
| 세로배너 | `표세로배너` | `표보기` |
| BASE 데이터 | `표BASE` | `표배너` |
| 보기 / 값 | `표보기` / `표숫자` | 기존 설정 유지 |

다단 헤더에서는 인식된 헤더 구간의 마지막 행을 머리행으로, 그 위의 배너를 가로배너로
처리한다. 머리행의 서식과 다음 페이지에서 반복할지 여부는 별개다. 표 상단의 BASE 안내행은
원본 BASE 데이터와 구분하며 오른쪽 정렬·무테두리 규칙을 유지한다.

## 템플릿에서 필요한 값만 가져오기

1. 아래쪽 **표 스타일** 목록에서 설정할 스타일을 선택한다.
2. **템플릿 셀 가져오기**로 `.hwpx` 파일을 선택한다. `.hwp`는 먼저 한글에서 HWPX 사본으로 저장한다.
3. 표 번호와 셀 좌표·내용을 확인하고, 적용할 속성만 체크한다.
4. **선택 적용**으로 편집기에 반영한 뒤 **새로 저장** 또는 **덮어쓰기**로 저장한다.

가져올 수 있는 값은 글꼴, 크기, 굵기, 가로/세로 정렬, 단색 배경, 선과 안쪽 여백이다. 같은 셀의 글자에
여러 값이 섞인 속성이나, 글꼴을 공통 이름으로 표현할 수 없는 경우는 목록에서 제외한다.
표 폭·병합 구조와 셀 내용은 복사하지 않는다. 가져오기를 취소하면 편집기에
반영하지 않으며, 적용 버튼만 눌러서는 저장되지 않는다. 원본 HWPX는 수정하지 않는다.

### 선·여백·글꼴

- **선:** 원본 셀의 위·아래·좌·우 중 한 선을 고르고, 외곽선·내부 가로선·내부 세로선·머리행
  아래선 중 한 곳에 지정한다. 종류·굵기·색만 가져온다. 실선, 없음, 점선, 파선, 가는 이중선을
  지원하며 그 외 종류는 목록에서 제외한다.
- **셀 안쪽 여백:** 원본 셀이 자체 여백을 사용하면 그 값, 아니면 표의 기본 안쪽 여백을
  가져온다. 선택한 역할에 `상/하/좌/우` 순서로 mm 값을 저장한다. 빈칸은 표 기본값을 사용한다.
  실제 저장 단위를 보존하기 위해 가져온 mm 값은 원래 입력한 정수와 약간 다를 수 있다.
- **글꼴:** 위쪽 문단 스타일 목록에서 대상 행을 고른 뒤 **글꼴 선택**을 눌러 Windows에
  설치된 글꼴, 크기, 굵기를 지정한다. 지원하는 속성만 저장하며, 기존 글꼴 이름의 직접 입력도 가능하다.

### 직접 지정

- **배경색:** 아래쪽 표 스타일 목록에서 역할을 선택하고 **셀 배경색**을 누른다. RGB 직접 입력도 가능하다.
- **선:** **선 설정**에서 외곽선·내부 가로선·내부 세로선·머리행 아래선을 하나씩 선택해 종류,
  굵기, 색을 편집한다. **기본값**을 선택하면 그 위치의 개별 설정만 지운다.
- **저장:** **새로 저장** 또는 **덮어쓰기** 후 프리셋을 선택한다. 한 보고서의 모든 표에
  같은 프리셋이 적용된다. 표마다 다른 프리셋을 배정하는 기능은 없다.

개별 지정하거나 가져온 선은 기존 외곽/내부 굵기·색보다 우선한다. 머리행 아래선은 내부 가로선보다 우선하며
공유 경계 양쪽에 같은 값이 들어간다. 좌우 외곽선 숨김과 BASE 안내행 무테두리는 유지한다.
여백은 표 폭 계획과 Excel 임시 표의 줄바꿈 높이에 반영한다. 병합 셀은 병합 폭을 기준으로
글자가 들어갈 폭을 확인한다. 공간이 없으면 삽입 전에 차단한다.

집계표의 기본 위·아래 안쪽 여백은 각각 0.3mm이며, 역할별 여백을 지정하면 그 값을 우선한다.
Excel 붙여넣기용 임시 표는 역할별 글자 크기·줄간격·병합 폭에 맞춰 행 높이를 계산한다.
용지에 들어가지 않는 경우에는 글자를 임의로 줄이지 않고, 머리행을 반복해 다음 페이지로 이어진다.

기존 스키마 `1.0`과 사용자 서식 3개 제한은 유지한다. 개별 스타일을 저장한 경우에만
`paragraph_styles`와 `table_cell_styles`에 같은 이름으로 추가된다. 기존 프리셋은 기본
스타일을 그대로 사용한다. 일반 작성 경로에서는 템플릿 프로필에서 추측한 대표 글자 크기보다
사용자가 선택한 이름 스타일을 적용한다.

## 검증

- 전체 Python 테스트 216개 통과, 1개 건너뜀, 하위 검사 32개 통과.
- 단일 EXE 검사에서 머리행 배경/크기·여백·선 설정의 저장과 재사용, 공통 배너 불변 확인.
- 한글 13.0.0.711에서 합성 Excel의 다단 헤더와 가로·세로 병합을 사용해 계약 기반 표와
  실제 Excel 붙여넣기 표를 각각 생성했다. 저장된 셀의 좌표, 병합, 표시값, 역할별 속성이
  일치했다. 선택 셀에서 가져온 여섯 속성(양쪽 정렬 포함)의 실제 저장도 확인했다.
- 비교본: `outputs/hwp_roles_native_20261111/contract.hwpx`, `clipboard.hwpx`, `imported.hwpx`.
  동일 Python 프로세스에서 COM 작성기를 즉시 재실행한 경우 한글 연결이 한 번 실패했다.
  런처와 같은 별도 프로세스 실행에서는 성공했다. 실제 KISDI·다페이지 검수는 별도다.
- 선·여백 검증본: `outputs/hwp_lines_native_20261111/contract.hwpx`, `clipboard.hwpx`,
  `legacy.hwpx`. 실제 한글 저장 후 점선 외곽, 이중 머리행 경계, 숨긴 세로선, 병합 셀의
  비대칭 여백과 지정 글꼴을 확인했다. 두 병합표 모두 본문 폭 이내이고 원본 14개의 해시가 일치했다.
